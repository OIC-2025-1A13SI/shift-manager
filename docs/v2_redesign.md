# シフトマネージャー v2.0 リメイク仕様案（シフトボード準拠）

- 版：1.0（2026-11-27 利用者承認）
- 状態：段階①（v2.0.x）・段階②（v2.1.x）・段階③（v2.2.0）すべて実装済み。v2.3.0 で §11、v2.4.0 で §12 の修正
- 本書は shift_manager_design.md（v1.1）より優先する。v1 の仕様のうち本書で変更していないものは引き続き有効
- 根拠：2026-11-27 の利用者回答、シフトボード実機スクリーンショット7枚（claude/shiftboard_research.md）

## 1. 方針

シフトボードとほぼ同じ操作感（月カレンダー → 日付タップ → 追加シート → 入力画面）にし、次を加える。

- 希望シフトを LINE 提出用の書式でコピーする機能（v1 の書式・挨拶文・未入力→× の確認をそのまま使う）
- 確定シフトの管理と給料計算

勤務先は1つだけ（勤務先の選択欄・色分けは設けない）。見た目はシフトボードの配置・操作に近づけるが、ロゴやアイコン画像は使わない。

## 3. 画面構成

下部タブ：**確定シフト**／**希望シフト**／**給料計算**／**その他**（2026-11-27 利用者の依頼で確定と希望の順を入れ替え。起動時に表示するのは希望シフト）

### 3.1 希望シフト（カレンダー）
- 上部バー：左にカレンダー⇔リストの切替、その右に LINE コピーボタン。中央に「2026年 12月」。左右スワイプか矢印で月を移動
- 月グリッド：日曜始まり、前後の月の日付は薄く表示、日曜は赤・土曜は青。選択中の日は薄い緑の背景
- マスには入力した希望を小さく表示（例：19-23、OP-LA、○、×）。未入力は空欄
- グリッドの下：選択日の見出し帯と、その日の希望（開始・終了の縦並び＋色の縦線）。下に破線枠の「＋シフトを追加」（入力済みなら「変更」）
- 「複数選択」ボタンで一括設定モード（R13）

### 3.2 追加シート（「＋シフトを追加」を押したとき）
下から出るシート。見出し「12月1日 (火) にシフト追加」。上から順に：
1. **曜日のいつもの**：その曜日に登録した希望があれば1行目に表示。ワンタップで入力
2. **○ 終日可能／× 勤務不可**：横並びのボタン
3. **履歴から追加**：最大10件のカード（開始・終了・ピン留め）。ピン留めした履歴は上に固定し、自動削除の対象外
4. **新規にシフトを入力する**：緑の全幅ボタン
- 入力済みの日は「未入力に戻す」も表示
- 入力すると翌日へ移り（R12）、シートは閉じる

### 3.3 シフトの入力画面（全画面）
- ヘッダー：左「×」、中央「シフトの追加」（編集時は「シフトの編集」）
- 開始：［時刻 / OP / 指定なし］の切替と、時刻チップ。チップを押すとすぐ下に時・分の2列ホイールが開く
- 終了：［時刻 / LA / 指定なし］の切替と時刻チップ（同上）
- 出力例（例：19-LA）と検証エラーを表示。v1 の入力検証（終了＞開始、両側指定なし不可、OP-・-LA 不可）を維持
- 最下部に緑の「完了する」

### 3.4 LINE コピー画面（「シフトの共有」に相当）
- ヘッダー「LINE提出用コピー」。対象期間は前半・後半の候補から選ぶ（表示中の月とその前後）
- プレビュー（挨拶文 ON/OFF を含む）
- 「コピーする」。未入力があれば v1 と同じ確認を出し、未入力は × でコピー

### 3.5 確定シフト（カレンダー）
- 希望シフトと同じ見た目のカレンダー。マスには確定時間を表示。給料日に ¥ 印
- グリッドの下：その日の**希望**（参考表示）と確定。確定は「開始・終了・休憩・一人シフト・時給」
- 日付をタップしたときのシート：
  1. **希望どおり**：その日の希望をそのまま確定にする。OP/LA は「その他」で登録したオープン・ラストの時刻で埋める。片側が「指定なし」や ○ の場合は、希望を初期値にして入力画面を開く。× や未入力のときは表示しない
  2. **曜日のいつもの（確定）**
  3. **確定の履歴**（最大10件、ピン留めあり）
  4. **新規に入力する**
  5. 確定済みなら「確定を取り消す」
- 上部メニュー：
  - **期間をまとめて確定**：前半・後半を選ぶと、未確定の日に希望を写す（「希望どおり」と同じ規則。時間が決まらない日はスキップして件数を表示）
  - **曜日のいつもので埋める**：前半・後半を選ぶと、未確定の日を曜日の型で埋める
- 確定の入力画面：開始・終了は時刻のみ（2列ホイール）、休憩（分）、一人シフト（スイッチ）、時給の個別設定（空欄なら基本時給）、メモ

### 3.6 給料計算
- 給料日ごとの見込み額：その給料日に対応する締め期間の確定シフトから計算
- 表示：見込み給料、勤務時間、出勤日数、目標額との差（棒グラフ）
- 内訳：通常分、深夜割増分、一人シフト加算分、交通費
- 希望だけで確定がない日は計算に入れない（「希望ベースの見込み」として別表示）

### 3.7 その他
- 給料の設定：基本時給、深夜割増（初期値 22:00〜翌5:00、25%）、一人シフト加算（＋円/時）、交通費（出勤1日あたり）、締め日、給料日、目標額
- オープン・ラストの時刻（OP/LA を確定にするときに使う）
- 曜日のいつもの：日〜土ごとに1つ（希望・確定で共通、§11）
- 希望シフトのまとめて入力は希望シフト画面の「いつもので埋める」（§11）
- 挨拶文、バックアップ（v1 と同じ。復元は全置換）、バージョン情報

## 4. 給料の計算規則（案）

- 1日の時給 ＝（時給の個別設定 または 基本時給）＋（一人シフトなら加算額）
- 深夜時間（22:00〜翌5:00）の分は時給 ×（1 ＋ 割増率）
- 休憩はまず深夜以外の時間から差し引く（実際の休憩時刻が不明なため）
- 1円未満は日ごとに切り捨て
- 交通費は確定シフトがある日ごとに加算
- 締め日が末日、給料日が翌月15日のような設定に対応する

## 5. データ（schemaVersion 2）

- hopes：日付 → 希望（v1 の requests をそのまま移行）
- confirmed：日付 → { start, end（分）, breakMinutes, solo, hourlyWage?, memo? }
- hopeHistory / confirmedHistory：最大10件、pinned フラグ付き（v1 の history は hopeHistory へ移行）
- weekdayTemplates：曜日 → { hope?, confirmed? }
- pay：基本時給、深夜割増、一人加算、交通費、締め日、給料日、目標額、オープン・ラストの時刻
- settings：挨拶文
- v1 のバックアップファイルも読み込める（自動で v2 に変換）

## 6. 進め方（案）

利用者が途中から使えるよう、3段階に分けて公開する。

1. 希望シフトのカレンダー化（3.1〜3.4、曜日のいつもの、データ移行）
2. 確定シフト（3.5）
3. 給料計算（3.6、給料の設定）

## 7. 確認結果（2026-11-27）

- §4 の計算規則（休憩は深夜以外から差し引く、1円未満は日ごとに切り捨て）：承認
- 3段階に分けて公開：承認

## 8. 段階①での実装上の解釈

- 起動時は「今日」を選択し今月を表示する（v1 の Q03「期間の初日を選択」は期間選択画面の廃止に伴い置き換え）
- 入力画面の初期値（Q11）：選択日の時間 → 曜日のいつもの → 最後に使った時間（ピン留めに関係なく最終使用日時が最新のもの）→ 19:00〜23:00
- 曜日のいつもの（希望）の登録画面の初期値：登録済みの時間、なければ 19:00〜23:00
- 複数選択中は表示中の月の日付だけを選べる
- 履歴のピン留め：ピン留めしたものは先頭に固定し、自動削除しない。10件すべてがピン留めのときは新しい時間を履歴に追加しない
- LINEコピー画面の初期期間は「今日を含む半月の次の半月」（提出先の期間）。候補は表示中の月とその前後の前半・後半
- 確定シフト・給料計算タブは「準備中」表示

## 9. 段階②（確定シフト）での実装上の解釈

- 確定の入力後も希望と同じく翌日へ移る（月末は翌月1日）。取り消しでは移動しない
- 確定タブのマス：確定は緑の塗り、未確定の日は希望を枠線付きの灰色で参考表示（× は薄い赤）
- 「希望どおり」：希望が ×・未入力の日はボタンを出さない。時刻が決まらない（片側が指定なし、OP/LA の時刻が未登録など）場合は、決まった側を初期値にして入力画面を開き、理由を表示する
- 「希望どおり」で既に確定がある日を確定し直す場合、休憩・一人シフト・時給・メモは引き継ぐ
- 確定の履歴は時刻と休憩を記録する（一人シフト・時給・メモは日ごとの情報のため記録しない）。「まとめて確定」は履歴に入れない
- 複数選択で「希望どおり」：決まる日だけ確定し、決まらなかった日数を表示する
- 確定の入力画面の初期値：確定済みの値 → 希望から決まる時刻 → 曜日のいつもの（確定）→ 最後に使った確定 → 19:00〜23:00
- 休憩は 0〜（勤務時間−1）分の整数、時給の個別設定は 0〜100,000 円の整数、メモは200文字まで
- オープン・ラストの時刻の初期案は 10:00 / 29:00（翌5:00）。未登録が初期状態
- 給料日の ¥ 印は段階③（給料の設定を作るとき）に表示する

## 10. 段階③（給料計算）での実装上の解釈

- 計算は §4 のとおり。深夜割増は一人シフト加算後の時給に掛かる（2026-11-27 回答）
- 内訳：深夜割増分・一人シフト加算分はそれぞれ日ごとに1円未満切り捨て、通常分は「日の合計 − 深夜割増分 − 一人シフト加算分」（日ごとの切り捨ての差を通常分で吸収し、内訳の合計と総額を一致させる）
- 給料日：「締め日（末日または1〜28日）」「給料日の月（当月・翌月・翌々月）」「給料日（末日または1〜28日）」で決める。対象期間は「前の締め日の翌日〜締め日」
- 給料計算タブは、今日以降で最初の給料日を初期表示する。‹ › で前後の給料日、日付を押すと次の給料日に戻る
- 基本時給が未設定の日は、時給の個別設定がある日だけ計算する（未設定の日は金額に含めず、注意を表示）
- 「まだ確定していない希望の日」：確定がない日の希望を「希望どおり」と同じ規則で時刻にし、休憩なし・一人シフトなし・交通費ありで見込みを出す（決まらない日は件数だけ表示）
- 目標額との差は横棒（進み具合）で表示
- 確定シフトのカレンダーで、給料日のマスに ¥ 印。給料日を選ぶとその給料日の見込み額を表示し、押すと給料計算タブへ移る
- 深夜の時間帯は 10:00〜30:00 の範囲で設定できる（終わりは始まりより後）

## 11. 利用後の修正（2026-11-27、v2.3.0）

| # | 依頼 | 対応 |
|---|---|---|
| 1 | その他の曜日のいつものを開くと戻れない | iPhone の Safari では、シートの外（暗い部分）のタップが反応しないことがあった。すべてのシートに「✕」を付け、上部を下にスワイプしても閉じるようにした。外側のタップも反応するよう修正 |
| 2 | 曜日のいつものは確定と希望で同じものを使う | 曜日のいつものを1つにまとめた（希望の型を確定にも使う）。確定では「希望どおり」と同じ規則で時刻にする（OP/LA はオープン・ラストの時刻）。その他の「曜日のいつもの（確定）」は削除。以前に登録した確定用の型は使わない |
| 3 | 希望をもとに確定したら、その場で時間を直したい | 確定シートの「希望をもとに確定」は、希望の時間を入れた入力画面を開くように変更（休憩・一人シフト・時給もその場で入力）。複数選択・期間をまとめて確定は従来どおり一括で確定 |
| 4 | 確定のカレンダーに希望の時間は出さない | 確定シフトのカレンダー・リストから希望の表示を外した。選んだ日の欄の「希望：19-23」は残す |
| 5 | 希望をいつもので埋めるは希望シフト画面で | 希望シフト画面の右上に「いつもので埋める」ボタンを置き、その他からは外した |

補足：確定シートの「曜日のいつもの」は、時刻が決まれば1タップで確定、決まらなければ入力画面を開く。

## 12. 利用後の修正 その2（2026-11-27、v2.4.0）

| # | 依頼 | 対応 |
|---|---|---|
| 1 | いつもので埋める・提出用コピーは表示中の月の前半・後半だけ | どちらも候補を「表示中の月の前半・後半」の2つに限定。コピー画面は、提出先の期間（今日の次の半月）が表示中の月にあればそれを、なければ前半を最初に選ぶ |
| 2 | 確定シフトに希望の表示は一切いらない | 確定シフトの欄・シート・入力画面から「希望：…」の表示をすべて外した。「希望をもとに確定」ボタンにも時刻を出さない（押すと希望の時刻が入った入力画面が開くのは §11-3 のとおり） |
| 3 | 入れたシフトを削除できるように（確定・希望とも） | 日付を選んだときの欄で、入っているシフトの右にゴミ箱ボタン。確認なしで削除し、「削除しました」と表示 |
| 4 | シフトの詳細でその日の給料を表示 | 確定シフトの入力・編集画面に「この日の給料」を表示し、時刻・休憩・一人シフト・時給を変えるとその場で再計算。日付を選んだときの欄にも金額を表示。交通費は別に足す旨を表示 |
