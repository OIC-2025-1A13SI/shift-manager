# シフトマネージャー v2.0 リメイク仕様案（シフトボード準拠）

- 版：1.0（2026-11-27 利用者承認）
- 状態：段階① 実装済み（v2.0.0）。段階②（確定シフト）・③（給料計算）は未着手
- 本書は shift_manager_design.md（v1.1）より優先する。v1 の仕様のうち本書で変更していないものは引き続き有効
- 根拠：2026-11-27 の利用者回答、シフトボード実機スクリーンショット7枚（claude/shiftboard_research.md）

## 1. 方針

シフトボードとほぼ同じ操作感（月カレンダー → 日付タップ → 追加シート → 入力画面）にし、次を加える。

- 希望シフトを LINE 提出用の書式でコピーする機能（v1 の書式・挨拶文・未入力→× の確認をそのまま使う）
- 確定シフトの管理と給料計算

勤務先は1つだけ（勤務先の選択欄・色分けは設けない）。見た目はシフトボードの配置・操作に近づけるが、ロゴやアイコン画像は使わない。

## 3. 画面構成

下部タブ：**希望シフト**／**確定シフト**／**給料計算**／**その他**

### 3.1 希望シフト（カレンダー）
- 上部バー：左にカレンダー⇔リストの切替、その右に LINE コピーボタン。中央に「2026年 12月」。左右スワイプか矢印で月を移動
- 月グリッド：日曜始まり、前後の月の日付は薄く表示、日曜は赤・土曜は青。選択中の日は薄い緑の背景
- マスには入力した希望を小さく表示（例：19-23、OP-LA、○、×）。未入力は空欄
- グリッドの下：選択日の見出し帯と、その日の希望（開始・終了の縦並び＋色の縦線）。下に破線枠の「＋シフトを追加」（入力済みなら「変更」）
- 「複数選択」ボタンで一括設定モード（R13）

### 3.2 追加シート（「＋シフトを追加」を押したとき）
下から出るシート。見出し「12月1日 (火) にシフト追加」。上から順に：
1. **曜日のいつもの**：その曜日に登録した希望があれば1行目に表示。ワンタップで入力
2. **○ 終日可能／× 勤務不可**：横並びのボタン
3. **履歴から追加**：最大10件のカード（開始・終了・ピン留め）。ピン留めした履歴は上に固定し、自動削除の対象外
4. **新規にシフトを入力する**：緑の全幅ボタン
- 入力済みの日は「未入力に戻す」も表示
- 入力すると翌日へ移り（R12）、シートは閉じる

### 3.3 シフトの入力画面（全画面）
- ヘッダー：左「×」、中央「シフトの追加」（編集時は「シフトの編集」）
- 開始：［時刻 / OP / 指定なし］の切替と、時刻チップ。チップを押すとすぐ下に時・分の2列ホイールが開く
- 終了：［時刻 / LA / 指定なし］の切替と時刻チップ（同上）
- 出力例（例：19-LA）と検証エラーを表示。v1 の入力検証（終了＞開始、両側指定なし不可、OP-・-LA 不可）を維持
- 最下部に緑の「完了する」

### 3.4 LINE コピー画面（「シフトの共有」に相当）
- ヘッダー「LINE提出用コピー」。対象期間は前半・後半の候補から選ぶ（表示中の月とその前後）
- プレビュー（挨拶文 ON/OFF を含む）
- 「コピーする」。未入力があれば v1 と同じ確認を出し、未入力は × でコピー

### 3.5 確定シフト（カレンダー）
- 希望シフトと同じ見た目のカレンダー。マスには確定時間を表示。給料日に ¥ 印
- グリッドの下：その日の**希望**（参考表示）と確定。確定は「開始・終了・休憩・一人シフト・時給」
- 日付をタップしたときのシート：
  1. **希望どおり**：その日の希望をそのまま確定にする。OP/LA は「その他」で登録したオープン・ラストの時刻で埋める。片側が「指定なし」や ○ の場合は、希望を初期値にして入力画面を開く。× や未入力のときは表示しない
  2. **曜日のいつもの（確定）**
  3. **確定の履歴**（最大10件、ピン留めあり）
  4. **新規に入力する**
  5. 確定済みなら「確定を取り消す」
- 上部メニュー：
  - **期間をまとめて確定**：前半・後半を選ぶと、未確定の日に希望を写す（「希望どおり」と同じ規則。時間が決まらない日はスキップして件数を表示）
  - **曜日のいつもので埋める**：前半・後半を選ぶと、未確定の日を曜日の型で埋める
- 確定の入力画面：開始・終了は時刻のみ（2列ホイール）、休憩（分）、一人シフト（スイッチ）、時給の個別設定（空欄なら基本時給）、メモ

### 3.6 給料計算
- 給料日ごとの見込み額：その給料日に対応する締め期間の確定シフトから計算
- 表示：見込み給料、勤務時間、出勤日数、目標額との差（棒グラフ）
- 内訳：通常分、深夜割増分、一人シフト加算分、交通費
- 希望だけで確定がない日は計算に入れない（「希望ベースの見込み」として別表示）

### 3.7 その他
- 給料の設定：基本時給、深夜割増（初期値 22:00〜翌5:00、25%）、一人シフト加算（＋円/時）、交通費（出勤1日あたり）、締め日、給料日、目標額
- オープン・ラストの時刻（OP/LA を確定にするときに使う）
- 曜日のいつもの：日〜土ごとに希望（全種類）と確定（時刻・休憩）を登録
- 希望シフトのまとめて入力：前半・後半を選び、未入力の日を曜日のいつもので埋める
- 挨拶文、バックアップ（v1 と同じ。復元は全置換）、バージョン情報

## 4. 給料の計算規則（案）

- 1日の時給 ＝（時給の個別設定 または 基本時給）＋（一人シフトなら加算額）
- 深夜時間（22:00〜翌5:00）の分は時給 ×（1 ＋ 割増率）
- 休憩はまず深夜以外の時間から差し引く（実際の休憩時刻が不明なため）
- 1円未満は日ごとに切り捨て
- 交通費は確定シフトがある日ごとに加算
- 締め日が末日、給料日が翌月15日のような設定に対応する

## 5. データ（schemaVersion 2）

- hopes：日付 → 希望（v1 の requests をそのまま移行）
- confirmed：日付 → { start, end（分）, breakMinutes, solo, hourlyWage?, memo? }
- hopeHistory / confirmedHistory：最大10件、pinned フラグ付き（v1 の history は hopeHistory へ移行）
- weekdayTemplates：曜日 → { hope?, confirmed? }
- pay：基本時給、深夜割増、一人加算、交通費、締め日、給料日、目標額、オープン・ラストの時刻
- settings：挨拶文
- v1 のバックアップファイルも読み込める（自動で v2 に変換）

## 6. 進め方（案）

利用者が途中から使えるよう、3段階に分けて公開する。

1. 希望シフトのカレンダー化（3.1〜3.4、曜日のいつもの、データ移行）
2. 確定シフト（3.5）
3. 給料計算（3.6、給料の設定）

## 8. 段階①での実装上の解釈

- 起動時は「今日」を選択し今月を表示する（v1 の Q03「期間の初日を選択」は期間選択画面の廃止に伴い置き換え）
- 入力画面の初期値（Q11）：選択日の時間 → 曜日のいつもの → 最後に使った時間（ピン留めに関係なく最終使用日時が最新のもの）→ 19:00〜23:00
- 曜日のいつもの（希望）の登録画面の初期値：登録済みの時間、なければ 19:00〜23:00
- 複数選択中は表示中の月の日付だけを選べる
- 履歴のピン留め：ピン留めしたものは先頭に固定し、自動削除しない。10件すべてがピン留めのときは新しい時間を履歴に追加しない
- LINEコピー画面の初期期間は「今日を含む半月の次の半月」（提出先の期間）。候補は表示中の月とその前後の前半・後半
- 確定シフト・給料計算タブは「準備中」表示
